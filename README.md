# Sofia kids-activity platform (working name: Zani)

Round-by-round prototype. Every business, event and profile in `prototype/` is FICTIONAL.
Real businesses are added one by one, only after they agree.

- `prototype/index.html` — clickable mobile prototype. Open it in a browser; no build step.
  The map is OpenStreetMap data (OpenFreeMap tiles) recoloured to the Moms of Sofia palette, with Bulgarian labels.
